# Shelf: scientific (scientific discovery; verbatim from the owner's spec)

## Short form
Scientific discovery. Triage: written inclusion rule, record unread, cap. Hypothesis: measurement, direction, control, reject if not runnable. Design: materials on hand, ordered steps, kill failure, wait for scientist. Analyze: script from raw files, regenerate figure, separate result, flag single-outlier dependence. Update: cite the result, drop the failed branch, next measurement only. Manuscript: draft from result files, self-review labeled draft, human owns the claim.
Now: Robin-style loop is real. The model does not run the wet lab.

## Directive definitions
Triage. Apply a written inclusion rule. Exclude by the rule, not by vibe. Record what was not read. Cap the set before the deep pass.
Hypothesis. Name the measurement. Name the direction of change. Name the control. Reject a hypothesis that cannot be run.
Design. List materials a lab already has. List the steps in order. Name the failure that would kill the idea. Wait for a scientist to accept it.
Analyze. Run the script from raw files. Regenerate the figure from the script. Separate result from interpretation. Flag a result that depends on one outlier.
Update. Cite the result that forces the change. Drop the part of the old hypothesis that failed. Keep the part the result did not touch. Propose the next measurement only.
Manuscript. Draft from the result files. Label the self-review as a draft. Do not upgrade a draft review into a verdict. A human owns the claim.

## Status and ceiling
Robin is the measured case: literature agents propose, a lab runs the assay, an analysis agent reads the result, the hypothesis updates. The model did not run the wet lab. The AI Scientist can draft experiments, code, plots, and a self-review. The self-review is not a verdict.
* Triage. Assisted. Inclusion rules work when written. It still over-includes interesting papers. Medium-high chance.
* Hypothesis. Assisted. It can name a measurement and a control. Many hypotheses are not runnable. Medium chance runnable-only becomes the default.
* Design. Assisted draft, gated. It lists steps. A scientist still accepts. High chance the draft is routine. Low chance the accept gate disappears.
* Analyze. Reliable on tabular and sequencing scripts it can rerun. Weak on messy instrument files. Medium chance rerun-or-fail is reliable.
* Update. Assisted. It cites the result if the result is in the file. It keeps dead branches unless told to drop them. Medium chance.
* Manuscript. Assisted draft. Self-review overrates. Low chance a human stops owning the claim by 2027.
