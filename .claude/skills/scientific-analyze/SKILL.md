---
name: scientific-analyze
description: Use when raw tabular or sequencing files need a rerunnable script, regenerated figure, and stated result. Quiet for unparseable instrument files and for drafting prose.
---
## Trigger
Raw data files (CSV, TSV, count tables, sequencing outputs) are present and a result is wanted. Quiet when the files are proprietary instrument dumps no script can read: report "unsupported" instead.
## Done-when
check: exit-code
One program only: the analysis script, run from the raw files alone, exits 0. In that run it regenerates the figure, writes results.txt and interpretation.txt as separate files, and does a leave-one-out pass: if dropping any single point flips the result it prints "OUTLIER-DEPENDENT" in results.txt, and it exits non-zero if the flag is missing when a flip occurs. If the script cannot run, the result is "rerun failed" and nothing is claimed. Unsupported input is a valid result.
## Rung
rung: L0
The script exit code is the check. A model may write the script once; escalate only if the rerun exits non-zero.
## Forbidden move
Reporting a result from a number the script did not produce, or a figure not regenerated by the script. Also hiding single-outlier dependence: if dropping one point flips the result, say so.
## Tool
tool: Bash:python3
scope: read
