---
name: scientific-analyze
description: Use when raw tabular or sequencing files need a rerunnable script, regenerated figure, and stated result. Quiet for unparseable instrument files and for drafting prose.
---
## Trigger
Raw data files (CSV, TSV, count tables, sequencing outputs) are present and a result is wanted. Quiet when the files are proprietary instrument dumps no script can read: report "unsupported" instead.
## Done-when
check: exit-code
One check only: the verifier, not the author of the script, reruns the analysis script in a clean directory holding only the raw files, with `python3 <script>`, and the exit code must be 0. Non-zero, a missing script, or a skipped rerun means "rerun failed" and nothing is claimed. Unsupported input (unparseable instrument files) is a valid result.
Procedure the script follows, not part of this check: regenerate the figure, write result and interpretation as separate files, run leave-one-out and print OUTLIER-DEPENDENT when dropping one point flips the result.
## Rung
rung: L0
The independent rerun exit code is the check. A model may write the script once; escalate only if the rerun exits non-zero.
## Forbidden move
Reporting a result from a number the script did not produce, or a figure not regenerated by the script. Also hiding single-outlier dependence: if dropping one point flips the result, say so.
## Tool
tool: Bash:python3
scope: read
