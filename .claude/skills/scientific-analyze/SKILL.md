---
name: scientific-analyze
description: Use when raw tabular or sequencing files need a rerunnable script, regenerated figure, and stated result. Quiet for unparseable instrument files and for drafting prose.
---
## Trigger
Raw data files (CSV, TSV, count tables, sequencing outputs) are present and a result is wanted. Quiet when the files are proprietary instrument dumps no script can read: report "unsupported" instead.
## Done-when
check: exit-code
One command, the desk's clean-rerun program (not yet in desk/ or fixtures/), run by the verifier, not the script's author, on the script and raw files in a clean directory. It exits 0 only if: the script rerun exits 0; the figure file is regenerated by that rerun; result and interpretation are separate non-empty files; and the output carries an OUTLIER-DEPENDENT or OUTLIER-INDEPENDENT line from leave-one-out. Non-zero, a missing script, or a skipped rerun claims nothing. Unsupported input (unparseable instrument files) is a valid result.
## Rung
rung: L0
The program's exit code is the check. A model may write the script once; escalate only if it exits non-zero.
## Forbidden move
Reporting a result from a number the script did not produce, or a figure not regenerated by the script. Also hiding single-outlier dependence: if dropping one point flips the result, say so.

tool: Bash:python3
